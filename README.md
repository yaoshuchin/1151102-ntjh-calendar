# 南投縣立南投國民中學 115學年度第一學期行事曆互動系統

本專案依據校方核定之「**11501全校行事曆0821完整.doc**」（南投國中 115學年度第一學期，民國 115 年 / 2026 年秋季 ~ 2027 年 1 月），自動解析出全學期 21 週完整教學與行政日程，並建立視覺化、可即時搜尋篩選與匯出日曆的網頁系統。

---

## 🌟 核心功能特色

1. **雙模式切換檢視**：
   - 📑 **【週次行事曆表】**：完整還原學校原公文與紙本表格排版（左側月份/週次、日～六日期，右側三欄：教務處/進修部、學務處、輔導室/總務處），配有考試、節日、活動之高亮色彩標記。
   - 🗓️ **【清單卡片速查】**：適合手機、平板或快速檢索，以卡片流呈現每一事項、日期區間與負責處室。
2. **多維度即時篩選**：
   - 🔍 **關鍵字即時搜尋**：輸入「段考」、「補考」、「隔宿露營」、「戶外教育」、「美展」、「體檢」、「休業式」等關鍵字即時反白過濾。
   - 🏢 **處室分類**：全部、教務處/進修部、學務處、輔導室/總務處。
   - 📅 **月份快速切換**：8月、9月、10月、11月、12月、1月。
   - 🏷️ **事項類型篩選**：考試測驗、放假節日、活動競賽、重要校務、例行集會、校務行政。
3. **雲端行事曆整合與匯出**：
   - 📲 **一鍵匯出 .ICS 檔案**：相容 Google Calendar、Apple 行事曆、Microsoft Outlook，手機/電腦皆可一鍵匯入。
   - 📅 **單一事項加入 Google 日曆**：點擊任一活動卡片彈出視窗，可直接將該活動加入個人 Google 日曆。
   - 📊 **匯出 Excel (CSV)**：完整結構化資料匯出，支援繁體中文（UTF-8 with BOM，Excel 開啟不亂碼）。
   - 🖨️ **友善排版列印**：支援 A4 橫式列印，自動隱藏非必要按鈕。
